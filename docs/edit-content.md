# 원고를 직접 고치기 — GitHub 웹에서

앱을 안 띄우고, 터미널도 안 쓰고, 브라우저만으로 본문을 고치는 방법.

**자동으로 반영되지 않는다.** GitHub에 저장하는 것과 내 노트북에서 도는 앱에
반영되는 것은 별개다. 아래 2단계까지 해야 화면이 바뀐다.

---

## 1. 고치기

1. https://github.com/Kimohoh/StoryTeller 로 간다
2. 브랜치가 `claude/spec-app-structure-vzwaxh` 인지 확인한다 (기본값이라 그냥 열면 맞다)
3. `content/` → 작품 폴더 → `ko.md`

| 작품 | 파일 |
|---|---|
| 변신 | `content/metamorphosis/ko.md` |
| 이방인 | `content/the-stranger/ko.md` |
| 시지프 신화 | `content/sisyphus/ko.md` |

4. 오른쪽 위 **연필 아이콘**을 누른다
5. 고친다
6. 아래로 내려 **Commit changes** → 무엇을 고쳤는지 한 줄 적고 → **Commit directly to
   the `claude/...` branch** 선택 → 초록 버튼

여기까지가 저장이다.

## 2. 내 컴퓨터에 반영하기

터미널 ①(앱이 도는 창)에서 `Ctrl+C` 로 앱을 멈추고, 한 줄씩:

```
git pull origin claude/spec-app-structure-vzwaxh
```
```
npm run build
```
```
ADMIN_TOKEN=storyteller-test-1234 npm start
```

터미널 ②(cloudflared)는 **건드리지 않는다.** 끄면 공개 주소가 바뀐다.

폰에서 볼 때는 홈 화면 아이콘 말고 브라우저로 주소를 열어 한 번 새로고침한다 —
서비스 워커가 이전 화면을 들고 있을 수 있다.

---

## 고쳐도 되는 것 / 건드리면 안 되는 것

### 고쳐도 된다

- 본문 문단 — 마음대로. 문장을 고치고, 나누고, 합치고, 문단을 더하고 빼도 된다
- `## 각색 원칙` 아래 목록
- `## 결과 화면 마지막 줄` 아래 인용 문단

### 건드리면 안 된다

**`>` 로 시작하는 문항 블록.**

```
> **Q5.** 첫 발포 뒤에 이어진 네 발의 총성은?
> - **A.** 첫 발과 같은, 공포와 당황이 시킨 일이다
> - **B.** 공포도 당황도 아닌, 다른 의도가 담긴 일이다
```

이 세 줄은 같은 내용이 `ko.json`에도 들어 있고, 빌드가 둘을 대조한다.
md만 고치면 **`npm run build`가 실패하면서** 어디가 어긋났는지 알려준다.
앱이 깨지지는 않지만 그 자리에서 멈춘다.

문항 문구를 바꾸고 싶으면 그냥 나한테 말하는 게 빠르다 — json과 결과 화면의
인용문, 논거까지 같이 맞춰야 한다.

**`## 1. 제목` 같은 장 제목 줄**도 json과 대조된다. 제목을 바꾸려면 두 파일을
같이 고쳐야 하므로 역시 나한테 말하는 편이 낫다.

**맨 위 `# 제목` 줄**도 마찬가지다.

---

## 실수했을 때

`npm run build` 가 빨간 글씨로 멈추면 그 메시지를 그대로 나한테 주면 된다.
GitHub에서 되돌리려면 파일 화면 오른쪽 위 **History** → 이전 커밋 → **Revert**.

원고는 전부 git에 있으므로 어떻게 고쳐도 잃어버리지 않는다.
