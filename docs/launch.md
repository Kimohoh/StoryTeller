# 배포와 알리기 (2026-08 조사)

아직 아무것도 구현하지 않았다. 도메인·호스팅 선택지와 알리는 방법을 정리해 둔다.

---

## 1. 도메인

**먼저 사야 할 것이 이것이다.** 스토어 등록보다 급하다. 터널 주소가 바뀔 때마다
공유된 결과 링크가 죽는 문제(`APP_ORIGIN`으로 대비만 해둔 그 문제)가 여기서 실제로 풀린다.

| | .com 1년 | 특징 |
|---|---|---|
| **Cloudflare Registrar** | **약 $10.5 (1.5만 원)** | 원가로만 판다. 마진을 안 붙이고 갱신가도 같다. 첫해 할인이 없는 대신 **2년차부터 안 오른다** |
| 가비아·후이즈 | 1.1만 원~ | 국내 결제·한글 지원. 갱신가가 오르는 경우가 있다 |
| 닷홈·카페24 | 5,500원~ | 첫해만 싸고 갱신가가 뛴다 |

**Cloudflare를 권한다.** 이 앱은 이미 Cloudflare Tunnel을 쓰고 있어 같은 계정에서
도메인·DNS·터널이 한 화면에 모인다. 첫해 몇천 원 차이보다 이게 크다.

이름은 짧고 한 번 듣고 받아적을 수 있어야 한다. `godok.kr`, `godok.app` 같은 형태.
`.kr`은 국내 대상이면 무난하고, `.app`은 **HTTPS가 강제**라 PWA와 잘 맞는다.

---

## 2. 서버 — Fly가 유일한 길이 아니다

이 앱의 제약은 하나다. **SQLite 파일을 디스크에 쓴다.** 그래서 서버리스(Vercel,
Netlify)는 그대로는 못 쓴다 — 쓰려면 DB를 외부(Turso, Neon)로 옮기는 개조가 필요하다.
디스크가 붙는 컨테이너나 VPS면 지금 코드 그대로 올라간다.

| | 월 비용 | 난이도 | 메모 |
|---|---|---|---|
| **Cloudflare Named Tunnel + 내 컴퓨터** | **0원** | 낮음 | 도메인만 있으면 **고정 주소가 공짜**. 지금 쓰는 quick tunnel과 달리 주소가 안 바뀐다. 대신 컴퓨터가 켜져 있어야 한다 |
| **Fly.io** | $2~5 | 중간 | Hobby $5(크레딧 $5 포함). 도쿄 리전이라 한국에서 가깝다. `fly.toml`이 이미 있다 |
| **Render** | $7 고정 | 낮음 | 요금이 정액이라 예측 가능. 디스크 붙는 Starter |
| **Railway** | $5~ | 낮음 | 사용량 과금. 배포는 가장 쉬운 축 |
| **Oracle Cloud Always Free** | 0원 | 높음 | 2026년에 2 OCPU/12GB로 반토막. 리전 용량 부족·계정 심사·유휴 회수가 잦다. **공짜지만 손이 많이 간다** |
| **Hetzner CAX11 (ARM)** | 약 $3.8 | 높음 | 가장 싸지만 독일이라 한국에서 멀다. 서버 관리는 직접 |
| **Vultr 서울/도쿄** | $6 | 높음 | 아시아 지연이 좋다. 역시 직접 관리 |

### 권하는 순서

**1단계 — 도메인 + Named Tunnel (월 0원).**
도메인만 사고 지금 쓰는 터널을 named tunnel로 바꾼다. **주소가 고정되고 비용은 0원이다.**
`APP_ORIGIN`에 그 도메인을 넣으면 공유 링크가 그때부터 안 죽는다.
한계는 하나 — 노트북이 꺼지면 사이트도 꺼진다. 지인 대상이면 이걸로 충분하다.

**2단계 — 사람이 늘고 24시간이 필요해지면 Fly 또는 Render.**
**주소를 안 바꾸고 원점만 옮긴다.** Cloudflare에서 DNS만 돌리면 되므로,
1단계에서 뿌린 링크가 그대로 산다. 이게 1단계를 먼저 하는 이유다.

- 손이 덜 가는 쪽 → **Render $7 정액**
- 싸고 도쿄에 두고 싶은 쪽 → **Fly $2~5** (설정 파일이 이미 있다)

**Oracle 무료는 권하지 않는다.** 공짜지만 계정 심사·용량 부족·유휴 회수로
"안 되는 날"이 생긴다. 월 $5를 아끼려고 서비스가 조용히 죽는 위험을 사는 셈이다.

## 3. 알리기

### 이 앱이 가진 것

**제목이 그대로 콘텐츠다.** 네 편의 제목만 나열해도 사람들이 멈춘다.

- 엄마, 내가 바퀴벌레가 되면 어떡할 거야? — 『변신』
- 모든 일에 이유가 있어야 해? — 『이방인』
- 아! 내일도 모레도 출근이야? — 『시지프 신화』
- 내 인생 최고의 밤, 할부 120개월 — 『목걸이』

밀리의서재가 2025년 3월 「세계 고전 문학의 달」에서 **작명왕 챌린지**(고전 제목을
현대적으로 재해석)를 이벤트로 돌렸다. 우리는 그걸 제품으로 갖고 있다.

**칭호가 자랑거리다.** "비탈 위, 별 곁의 바이올린" — 읽을수록 자란다.

### 먼저 만들어야 하는 것 하나

**공유 카드(OG 이미지)가 없다.** 지금 카카오톡에 링크를 붙이면 그림 없이 제목만 뜬다.
공유가 이 앱의 유일한 확산 경로인데 그 자리가 비어 있다.

- `app/result/[sessionId]/opengraph-image.tsx`로 유형·좌표·칭호가 박힌 카드를 그린다
- 작품 표지에도 같은 카드
- **규모: 하루.** 아래 어떤 채널보다 이게 먼저다

### 채널 (비용 순)

**0원**

| 채널 | 어떻게 |
|---|---|
| **인스타그램·스레드** | 제목 네 개를 카드뉴스 한 장으로. "이 제목이 무슨 고전인지 맞혀보세요" |
| **커뮤니티** | 디시 독서갤러리, 클리앙, 루리웹, 에브리타임. **직접 홍보 티가 나면 역효과다** — "고전 제목 현대식으로 바꿔봤다"로 시작하고 링크는 댓글에 |
| **트위터 문학 계정** | 각색문 한 문단을 이미지로. 출처를 앱으로 |
| **오픈카톡 독서모임** | 완독 후 결과를 서로 비교하는 용도로 제안 |
| **뉴스레터 소개 요청** | 문학·독서 뉴스레터에 "이런 걸 만들었다"고 메일. 회신율은 낮지만 걸리면 크다 |

**품이 드는 것**

- **SEO** — "변신 줄거리", "이방인 해석" 검색량이 크다. 각색 본문을 노출하면
  읽을 이유가 사라지므로, **작품 소개 페이지**를 따로 만들어 그쪽으로 받는다
- **브런치스토리 연재** — 각색 뒷이야기(왜 이 제목인지, 왜 이 문항인지)를 글로 쓰고
  본편은 앱으로. 지금까지의 작업 기록이 그대로 글감이다
- **출판사·구독 플랫폼 접촉** — `docs/bm.md` 참조. 완독률과 원작 클릭률이 모인 뒤

### 하지 말 것

- **유료 광고.** 지금 단계에서 돈으로 산 유입은 완독을 안 한다. 완독률이 흐려지면
  협상 재료가 사라진다
- **완독을 조건으로 한 이벤트·경품.** 답이 아니라 보상을 위해 읽는 사람이 섞이면
  축이 오염된다. 이 앱이 파는 것이 그 축이다

### 순서

1. 도메인 + named tunnel (반나절, 1.5만 원)
2. 공유 카드 (하루)
3. 커뮤니티 한 곳에서 반응 보기 — 완독률이 60%를 넘는지 확인
4. 넘으면 채널을 늘리고, 안 넘으면 각색문부터 손본다
