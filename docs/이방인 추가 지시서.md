# 작업 지시 — C축 도입 + 두 번째 작품(『이방인』) 추가

## 0. 전제

이 저장소에는 이미 `docs/spec.md`와 카프카 『변신』 프로토타입이 있다.
**기존 구조와 규칙을 그대로 유지한 채 확장한다.** 아래 중 하나라도 어기면 안 된다.

- 선택은 이야기를 분기시키지 않는다. 텍스트는 고정, 선택은 기록만 한다.
- 축은 읽는 중에 절대 노출하지 않는다. 진행 표시에 축 이름·측정 문구를 넣지 않는다.
- 문항은 전부 장면 내부의 구체적 행동으로 위장한다. 추상 질문 금지.
- 콘텐츠 JSON은 `illustration_key`만 참조한다. 파일 경로·확장자를 알지 못한다.
- 삽화 교체는 `assets/illustrations/manifest.json` 수정만으로 끝나야 한다.
- 채점은 클라이언트, 저장은 원본 선택. `answers`에 좌표를 저장하지 않는다.
- 퍼블릭 도메인 원문 + 자체 각색만 사용. 국내 출판 번역본 문장은 쓰지 않는다.

작품 파일 네이밍은 『변신』과 동일하게 간다.

```
content/<slug>.ko.md      사람이 읽고 고치는 각색 정본
content/<slug>.ko.json    앱이 먹는 구조
assets/illustrations/<slug>/<illustration_key>.svg
```

## 1. 작업 A — C축 도입

### 1-1. 축 정의

공통 축을 2개에서 **3개로 늘린다. 이후 더 늘리지 않는다.**

| 축 | 정의 | 양(+) | 음(−) |
|---|---|---|---|
| A | 책임의 소재 | 개인 | 바깥 |
| B | 의미 부여 | 서사 | 사실 |
| **C** | **판단의 근거가 바뀌었을 때** | **판단을 수정한다** | **판단을 유지한다** |

C축은 A·B와 측정 방식이 다르다. **자기보고가 아니라 행동 관찰이다.**
같은 것을 묻는 문항을 작품 전반부(`pre`)와 후반부(`post`)에 한 번씩 배치하고,
**두 응답이 달라졌는지 여부**가 점수가 된다. 문항 자체의 선택지 값은 C축 점수에 쓰이지 않는다.

### 1-2. 스키마 변경

`answers` 테이블에 두 컬럼을 추가한다.

```
answers  session_id, question_id, choice_id, answered_at,
         pair_id TEXT NULL,          -- 같은 페어면 동일 값. 예: "c1"
         phase   TEXT NULL           -- 'pre' | 'post' | NULL
         PK(session_id, question_id)
```

`questions`에도 동일하게 `pair_id`, `phase`를 둔다. C축 문항은 `axis='C'`.

**『변신』에도 이 컬럼을 지금 넣어둔다.** 현재 『변신』에는 C 문항이 없지만(전부 NULL),
4페이지 「밝혀지는 장부」가 C 지점에 해당하므로 나중에 문항 2개 추가로 소급 적용할 예정이다.
지금 컬럼만 열어두면 그때 마이그레이션이 필요 없다.

### 1-3. 채점 로직

A·B는 기존과 동일: `Σ(value × weight) / Σ(weight)` → −1.0 ~ +1.0

C는 페어 단위로 계산한다.

```
각 pair_id에 대해:
    pre 응답의 choice.value != post 응답의 choice.value  →  +1  (수정)
    같으면                                              →  −1  (유지)

C = Σ(페어 결과) / 페어 개수
```

규칙:

- **페어가 2개 미만인 세션에서는 C를 계산하지 않고 결과 화면에도 표시하지 않는다.**
  페어 1개로는 노이즈와 구별이 안 된다.
- C 페어가 하나도 없는 작품(현재 『변신』)은 그 작품 결과 화면에서 C를 생략한다.
  누적 좌표 화면에서는 C가 측정된 작품들만 모아 계산한다.
- pre 또는 post 중 하나라도 미응답이면 그 페어는 계산에서 제외한다.

`scoring_version`을 2로 올린다. 기존 v1 세션은 원본 선택이 남아 있으므로 소급 재계산 가능해야 한다.

### 1-4. 결과 화면

A·B 4분면은 그대로 두고, **C는 별도 지표로 아래에 붙인다.** 8분면으로 만들지 않는다.
유형 인구가 8등분되면 코멘트 밀도가 절반으로 떨어지고, 밀도가 이 앱의 자산이다.

C를 문장으로 제시할 때 **"일관성"이나 "줏대"처럼 가치 서열이 느껴지는 말을 쓰지 않는다.**
어느 쪽도 더 나은 태도가 아니어야 다음 작품에서 답을 연기하지 않는다.

C가 측정된 경우, 결과 화면에 실제 전후 응답을 나란히 보여준다.
"2페이지에서는 X를 골랐고, 7페이지에서는 Y를 골랐습니다" — 이게 C축의 증거이자 가장 강한 화면이다.

### 1-5. 반드시 지킬 것

**pre와 post 문항의 문면을 다르게 쓴다.** 같은 질문임이 드러나면
"일관되어 보이려고" 답을 고정하는 사람이 생겨 축이 죽는다.
전반부는 "당신이라면", 후반부는 "그런 사람을 어떻게 보는가"로 각도를 바꾼다.
UI에서도 두 문항을 연결지어 표시하지 않는다.

## 2. 작업 B — 『이방인』 콘텐츠 추가

알베르 카뮈, 1942년작. 카뮈는 1960년 1월 사망 → **한국에서 퍼블릭 도메인이다.**
(2013년 7월 1일 개정 저작권법 부칙에 따라 1962년 12월 31일 이전 사망 작가는 사후 50년 적용, 이미 만료.)
원문 기반 자체 각색만 사용하고, 국내 출판 번역본 문장은 인용하지 않는다.

- slug: `the-stranger`
- 제목은 미정. 『변신』과 같은 톤의 위트 있는 제목을 별도로 정할 예정이므로 `title`은 임시값으로 두고 TODO 주석을 남긴다.
- 10페이지 / 문항 8개 — A 3, B 3, C 페어 2쌍(문항 4개는 페어로 소진되므로 실제 고유 문항은 6 + 페어 2쌍)
- 로컬 축 없음. 3축으로 충분하다.

### 페이지 구성

| # | 장면 | 문항 |
|---|---|---|
| 1 | 오늘 엄마가 죽었다 — 전보, 양로원 도착 | `q1` **B** · 이 죽음에 정리할 것이 있는가 / 절차가 있을 뿐인가 |
| 2 | 밤샘 — 커피, 담배, 졸음 | `q2` **C** `pair=c1` `phase=pre` · 관을 열어보겠느냐는 물음에, 연다 / 열지 않는다 |
| 3 | 다음 날 — 마리, 해수욕, 코미디 영화 | `q3` **A** · 이 사람은 원래 이런 사람이다 / 아직 아무 말도 하지 않았다 |
| 4 | 레몽 — 이웃의 부탁, 편지 대필 | `q4` **A** · 거절했어야 한다 / 거절할 이유가 없었다 |
| 5 | 해변 — 태양, 그리고 네 발 더 | `q5` **C** `pair=c2` `phase=pre` · 첫 발과 나머지 네 발은 같은 일인가 / 다른 일인가 |
| 6 | 예심판사 — 십자가를 들이밀며 | `q6` **B** · 믿지 않는다고 말한다 / 대답하지 않는다 |
| 7 | 재판 — 검사가 장례식 이야기를 꺼낸다 | `q7` **C** `pair=c1` `phase=post` · 어머니의 관을 열지 않은 사람을 어떻게 보는가 |
| 8 | 판결 — "영혼이 없는 자" | `q8` **A** + `q9` **C** `pair=c2` `phase=post` · 네 발을 더 쏜 사람을 어떻게 보는가 |
| 9 | 사제 — 폭발 | `q10` **B** · 그가 쏟아낸 말은 깨달음인가 / 발악인가 |
| 10 | 결말 — 별, 세계의 다정한 무관심 | **질문 없음** |

### 설계 의도 (각색·구현 시 유지할 것)

- **q3은 함정이다.** 3페이지 시점에 독자가 뫼르소를 판단하게 만들고,
  2부에서 검사가 정확히 같은 근거로 사형을 구형한다.
  결과 화면에서 이 대응을 짚어주면 타격이 크다.
- **이 작품의 C축은 새 정보 없이 작동한다.** 사실은 하나도 바뀌지 않고 틀만 바뀐다.
  『목걸이』형(사실이 뒤집힘)과 대비되는 순수형이므로, 각색에서 새로운 사실을 추가하면 안 된다.
- **10페이지는 질문 없이 흘려보낸다.** 『변신』 9페이지와 같은 원칙.
  9페이지에서 답한 직후 결말이 그냥 지나가는 것이 이 작품의 타격점이다.
- 무게중심은 2부 재판이다. 1부를 압축하더라도 2부는 줄이지 않는다.

### 삽화

`illustration_key`는 `p1_telegram` … `p9_priest` 형식으로 10개 부여한다(10페이지는 `null` 가능).
실제 SVG는 아직 없다. **manifest에 키만 등록하고 플레이스홀더로 처리한다.**
삽화가 없을 때 레이아웃이 깨지지 않아야 하고, 나중에 파일만 추가하면 붙어야 한다.
